AI Usage Log — ABTalks Redesign

This log records the prompts used with AI tools (Claude and Gemini) while building this project, in the order they were given, as required by the hackathon's AI Usage Log guideline.

1 — Claude

Shared the ABTalks problem statement and asked Claude to design the site around it, with toggleable features and a theme system that evolves as a student's streak grows. Also asked for a step-by-step plan for a 3-person team to collaborate on GitHub with 3 commits each, with no conflicts.

2 — Claude

Provided the full official problem statement: the three required routes (/, /dashboard, /day/12), the GitHub-commit + LinkedIn-post daily proof requirement, the 390px mobile-first constraint, required edge cases (first day / missed day / empty profile), the out-of-scope list (authentication, real accounts, production database, recruiter dashboard, admin panel), and the mocked-data-only requirement.

3 — Claude

Requested a critical review of the draft: responsiveness across phone, tablet, and laptop; removal of unnecessary UI elements; and missing moments the interface lacked, like a student registration flow and a reward moment when a streak milestone is hit.

4 — Claude

Asked for a clearer landing page explaining what ABTalks is, a light/dark theme toggle (since students use the platform late at night), and confirmation the submission fields matched the problem statement — built to a polished, cross-device, launch-ready standard.

5 — Claude

A consolidated list of fixes and improvements after reviewing a build: saved name not showing on Profile/Ranks, only 4 tracks existing, and achievements not unlocking visually. Also requested day content for all 60 days instead of one, streak-based motivational copy, a missed-streak reminder module, richer profile fields, a language toggle, general UI/UX polish, and a final self-check against the original problem statement.
